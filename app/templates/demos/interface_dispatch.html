interface value (2 từ máy)
tab *itab
data unsafe.Pointer

itab

  • inter — kiểu interface (io.Writer)
  • _type — kiểu động (*os.File)
  • fun[0] — địa chỉ (*os.File).Write

dữ liệu

  • giá trị *os.File thực tế
  • nằm trên heap nếu escape

Một lời gọi w.Write(p) đi qua ba bước

  1. Đọc con trỏ itab từ interface value
  2. Tra địa chỉ hàm trong bảng fun
  3. Gọi hàm đó với data làm receiver

Đây cũng là lý do một interface chứa con trỏ nil vẫn khác nil: từ tab đã được điền, chỉ data là nil.
